# 📸 Divya Memory – Photography & Films

### ✨ Capturing Your Beautiful Moments

Divya Memory is a photography and films website designed to showcase beautiful memories and special occasions. It allows visitors to explore photography services, browse event portfolios, view packages, and submit booking enquiries.

The website focuses on an attractive design, easy navigation, and a user-friendly experience.

## 🌐 Live Website

🔗 **Visit Website:** https://divya-memory.onrender.com/

## 📂 GitHub Repository

🔗 **Source Code:** https://github.com/divyankakri7-oss/divya-memory

---

## ✨ Features

- 🏠 **Home Page:** Attractive landing page with photography branding.
- 👤 **About Section:** Information about the photography business.
- 📷 **Services:** Details of photography and videography services.
- 💰 **Packages:** Photography packages for different occasions.
- 🖼️ **Portfolio Gallery:** Displays photographs from various events.
- 💍 **Wedding Photography:** Wedding and pre-wedding portfolio.
- 🎂 **Birthday Photography:** Birthday celebration photography.
- 💖 **Anniversary Photography:** Special moments and celebrations.
- 📅 **Booking Form:** Interface for submitting photography booking enquiries.
- 📩 **Contact Section:** Contact information for potential customers.
- 📱 **Responsive Design:** Designed for a user-friendly browsing experience across different screen sizes.

## 🚀 Getting Started

Follow these steps to run the frontend locally.

### 1. Clone the Repository

```bash
git clone https://github.com/divyankakri7-oss/divya-memory.git
```

### 2. Open the Project Folder

```bash
cd divya-memory
```

### 3. Run the Frontend

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

### 4. Run the Backend

If your project includes a Node.js backend:

```bash
cd backend
npm install
node server.js
```

Configure the required environment variables and MySQL database before running the backend.
